Every Feature

Built different.
On purpose.

Every feature in GlassChat exists to give you more — more privacy, more expression, more control. Nothing is there to harvest your data.

🫥

Vanish Mode

When you close a Vanish Mode session, GlassChat simultaneously purges all local Room database records, deletes Firestore conversation documents, and removes every uploaded media file from cloud storage — on both devices at once. No traces, no recovery, no regrets.

✦ Both devices wiped simultaneously
📵

Screenshot Shield

Android's WindowManager.SECURE flag applied to every chat screen. Any screenshot attempt returns a blank black image. A filesystem watcher also detects attempts and alerts you in real-time inside the chat.

✦ Blank black on capture attempt
🤝

Connections Only

Strangers simply cannot message you. No cold DMs, no spam. Your profile is invisible unless you share your handle.

⚡

Offline-First

Messages hit your local Room SQLite DB first. UI responds instantly — even underground or in airplane mode. Auto-syncs when back online.

🔄

Real-time Sync

Firestore snapshot listeners push updates to both devices instantly. Typing indicators, read receipts, online presence, and message status — all live, all synchronized, no polling required.

✦ Live typing & read receipts
⏰

Smart Alarm System

Set per-contact alarm tones that cut through Do Not Disturb mode using Android's AlarmManager PRIORITY_ALARM — the same channel system clock alarms use. Never miss what matters.

✦ Bypasses DND like system alarms

Voice Notes

Record in AAC/MPEG-4 at 44100Hz. Waveform-style playback with progress bar, timestamps, and smart pause logic — one player at a time.

Video Messages

Private Image Storage

All images stored in private Supabase buckets with row-level security. Authenticated URLs only — no algorithm, no admin can view your photos.

Horizontal drag gesture with haptic feedback triggers a contextual reply thread — blue border, quoted sender, one-tap cancel. Long-press your own message to unsend it from Firestore and both devices simultaneously. Long-press received media to save to gallery.

Media Gallery + Full Search

Per-conversation gallery with 3 tabs: Images (3-column grid), Videos (with play overlay), Voice Notes (chronological list). Full-text search across all chats — find any message, photo reference, or thread instantly.

Privacy Architecture

Zero
compromise
security.

Every privacy feature is implemented at the OS and database level — not just a setting you can toggle off.

01

Secure Window Flags

Every chat activity applies FLAG_SECURE via WindowManager — screenshots, screen recordings, and screen previews all return black.

02

Dual-Wipe on Vanish Close

Room DB records deleted. Firestore docs deleted. Supabase media buckets purged. Both devices. Simultaneously. No async lag — it's a synchronized transaction.

03

Connection-Only Discovery

Search returns no results until a mutual connection exists. Your handle is invisible to all users until you share it personally.

04

File System Watcher

A background observer monitors the Screenshots directory. Any capture attempt fires an alert inside the active conversation in real-time.

Is GlassChat completely free?
Yes — completely free. No subscriptions, no ads, no in-app purchases, no hidden costs. Download the APK and every single feature is available immediately.
How does Vanish Mode actually work?
When you close a Vanish session, GlassChat executes a synchronized delete: all Room DB records are purged, the Firestore conversation document is deleted, and any uploaded media is removed from Supabase buckets. This happens on both devices at once — there is no recovery path.
Can anyone screenshot my chats?
No. GlassChat applies WindowManager SECURE flags to all chat screens — any screenshot or screen recording attempt produces a blank black image. Additionally, a file-system watcher alerts you inside the chat when a capture is attempted.
Are video and voice calls private?
Completely. Calls use WebRTC — a direct peer-to-peer technology where audio/video streams travel directly between the two devices. No server ever receives, records, or can intercept your call streams.
How does the alarm bypass Do Not Disturb?
GlassChat uses Android's AlarmManager with PRIORITY_ALARM and a foreground service with the AudioManager STREAM_ALARM channel — the same combination system clock alarms use. Android explicitly permits this to bypass DND.
Are my images stored anywhere?
Images are stored in private Supabase buckets accessible only to the two participants. No admin, no algorithm, no third party has access. In Vanish Mode, they're deleted entirely when the session ends.
Does it work offline?
Yes. GlassChat is built offline-first. All messages are written to local Room SQLite storage immediately, so the UI updates instantly without internet. When connectivity is restored, everything syncs to Firestore automatically.
What Android version is required?
GlassChat requires Android 8.0 (API 26) or higher. It's optimized for Android 14/15 and targets SDK 35 with full edge-to-edge display support.
