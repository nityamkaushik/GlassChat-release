Common Questions

Got questions? We've
got answers.

Is GlassChat really free?
Yes, completely free. No ads, no premium features, no hidden costs. We believe privacy shouldn't be a luxury.
How do you make money?
We don't. GlassChat is passion-driven. Made by privacy advocates, for people who care about their data.
Can you read my messages?
No. All messages are encrypted with AES-256-GCM before leaving your device. Keys are derived using X25519 ECDH and never transmitted. We can't decrypt messages even if we wanted to — it's mathematically impossible.
What encryption does GlassChat use?
AES-256-GCM for message encryption, X25519 ECDH for key exchange with HKDF-SHA256 derivation, SQLCipher for local database encryption, EncryptedSharedPreferences for credential storage, and per-file AES-256 keys for media encryption.
Are my media files encrypted?
Yes. Every media file (images, videos, voice notes, documents) is encrypted with a unique AES-256 key before upload. The file key is then encrypted with the conversation key and stored separately. Your cloud storage provider never sees plaintext content.
Is it open source?
We're working on it. The source code will be available soon for full transparency and community audits.
What about offline mode?
Messages are drafted and queued locally. Once you reconnect, they're sent automatically. No data loss, ever.
Does it work on other devices?
Currently Android only. iOS and web are on the roadmap for later this year.
